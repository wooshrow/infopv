PRISM Tutorial

  1. Download and install PRISM on your computer, if you have not done this yet in Week-1.

  2. Do the first tutorial, Knuth Die, from this tutorial. Then, do one more DTMC tutorial, namely Herman, and the Dining Philosophers tutorial for MDP.

  3. Document your findings from doing these tutorials in a Report of about 4-6 pages. A neat report is expected. Using Latex is recommended.
    • You don't need to copy and repeat the texts in in the tutorials. The tutorials contain instructions like "do this and see what happens" or questions to answer. Write down your findings/answers and give some motivation.
      Specifically for the Knuth Die tutorial, it includes a task where you compute the expected termination time of Knuth-Yao algorithm by hand (so, analytically). Show the set of equations that you use to do this, and show the result of your calculation.
    • Include visuals like graphs, tables, or screenshots when necessary to improve your Report's clarity.

  4. Hand in your documentation by simply emailing a PDF to me.
